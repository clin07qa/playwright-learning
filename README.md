## This is a project used to learn automation with Playwright

### Tech Stack
- Playwright  
- JavaScript  
- Faker.js (random test data generation)  
- Git  
- GitHub Actions (CI/CD)  

### Website Used
- https://www.automationexercise.com/

### Test Cases
- **User Login**
  - Login with a registered user  
  - Login with an invalid email and password  

- **User Registration**
  - Register a user with an existing email  
  - Register a new user  

- **Product Navigation**
  - Navigate from Product Landing Page to Product Details Page  

- **Contact Form**
  - Submit a contact form
